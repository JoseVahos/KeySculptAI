# 🚀 Instrucciones Rápidas - KeySculptAI

## ⚡ Inicio Rápido

### Opción 1: Scripts Automáticos (Recomendado)
1. **Doble clic** en `start_web_interface.bat`
2. **Abrir navegador** en http://localhost:5000
3. **¡Listo!** Ya puedes usar la interfaz

### Opción 2: Manual
1. Abrir terminal en la carpeta del proyecto
2. Ejecutar: `cd web-interface && python server.py`
3. Abrir http://localhost:5000 en el navegador

## 🎯 Uso de la Interfaz Web

### Panel de Control
- **🚀 Flujo Completo**: Ejecuta todo el proceso automáticamente
- **📊 Capturar Datos**: Inicia el keylogger
- **📈 Analizar Datos**: Procesa los datos capturados
- **⚡ Optimizar Layout**: Genera el layout optimizado
- **🎹 Aplicar Layout**: Activa el remapper
- **👁️ Lanzar Overlay**: Visualización en tiempo real

### Pestañas de Visualización
1. **Heatmap**: Ver frecuencias de uso de teclas
2. **Layout Optimizado**: Comparar QWERTY vs optimizado
3. **Logs**: Monitorear todas las operaciones

## 🔧 Solución de Problemas

### El servidor no inicia
- Verifica que Python esté instalado: `python --version`
- Instala Flask: `pip install flask flask-cors`

### Error de conexión
- Asegúrate de que el servidor esté ejecutándose
- Verifica que no haya otro proceso en el puerto 5000

### El remapper no funciona
- Ejecuta como administrador
- Verifica que tengas un layout optimizado generado

## 📞 Soporte
- Revisa los logs en la pestaña "Logs"
